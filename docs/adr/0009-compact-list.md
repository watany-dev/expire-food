# ADR 0009: 一覧を 1 行に詰め、期限ごとに区切って削除はスワイプで出す

- 状態: 採用
- 日付: 2026-09-26

## 背景

一覧は 1 件に商品名・期限日・残り日数の 3 行と、高さ 44px の削除ボタンを並べていた。1 件あたり約 120px になり、スマホの 1 画面に 5 件ほどしか見えない。いま見るべき期限切れ・期限間近の商品まで画面の外に出てしまう。

## 決定

- 1 件を 1 行（最低 44px）にする。商品名・種別の略称（賞味 / 消費）・短い期限日（今年なら `M/D`、それ以外は `YY/M/D`）・残り日数を並べ、行全体を編集画面へのリンクにする
- 「期限切れ / N日以内 / それ以降」に区切り、見出しに件数を出す。N は 14 日と `warn_days - 1` の大きい方にして、黄色の商品が「それ以降」に入らないようにする（`groupByDeadline`、`src/domain/status.ts`）
- 「それ以降」は先頭 2 件だけ出し、残りは `<details>` に畳む。JS は使わない
- 「＋ 追加」はヘッダーの「設定」の隣に移す
- 削除ボタンは行の右の画面外に置き、左にスワイプすると出す。横スクロール（`overflow-x`）と `scroll-snap` だけで作り、JS は使わない（ADR 0002）。確認ダイアログはこれまでどおり `popover`
  - ボタンは DOM に残るので、キーボードでフォーカスすれば表示される。マウスでは横スクロールで出す

## 影響

- 削除ボタンが見えないので、スワイプできることに気づきにくい。気づかれないようなら、編集画面にも削除を置く
- 行を横にスクロールしたままでも閉じる操作はない（削除すると一覧を読み直すので、開いたまま残るのは削除しなかった行だけ）
